# Student Management System

Консольная система учёта студентов на C++ с разграничением прав доступа,
валидацией ввода и сохранением данных в бинарный файл.

## 📋 Возможности

- **Три роли пользователя:** администратор, преподаватель, студент
- **Управление студентами:** добавление, удаление, просмотр
- **Успеваемость:** добавление оценок, автоматический подсчёт среднего балла
- **Домашние задания:** выдача заданий по группам с дедлайнами
- **Посещаемость:** отметка присутствия студентов на занятиях
- **Расписание:** добавление пар по группам с указанием дня, времени и аудитории
- **Валидация ввода:** проверка имён, групп, дат и времени через регулярные выражения
- **Сохранение данных:** автоматическая запись в бинарный файл `students.db`
- **Аутентификация студентов:** вход по ID и паролю

## 🛠 Требования

- **Компилятор:** C++17 или новее (g++, clang++, MSVC)
- **ОС:** Windows (рекомендуется), Linux, macOS
- **Стандартная библиотека:** `<regex>`, `<fstream>`, `<vector>`, `<sstream>`

## 🚀 Сборка и запуск

### Windows (MinGW / MSVC)

```bash
g++ -std=c++17 -O2 kursovaya2.cpp -o student_system.exe
student_system.exe
```

### Linux / macOS

```bash
g++ -std=c++17 -O2 kursovaya2.cpp -o student_system
./student_system
```

> ⚠️ **Важно:** на Windows программа переключает кодировку консоли на CP1251
> (`chcp 1251`). Исходный файл должен быть сохранён в **Windows-1251**,
> иначе русские буквы и regex-валидация будут работать некорректно.

## 📖 Использование

После запуска откроется главное меню. По умолчанию активна роль **администратора**.

### Роли и доступные действия

| Действие | Админ | Преподаватель | Студент |
|---|:---:|:---:|:---:|
| Добавить студента | ✅ | ❌ | ❌ |
| Удалить студента | ✅ | ❌ | ❌ |
| Добавить расписание | ✅ | ❌ | ❌ |
| Показать студентов | ✅ | ✅ | ❌ |
| Показать оценки всех | ✅ | ✅ | ❌ |
| Добавить оценку | ✅ | ✅ | ❌ |
| Добавить ДЗ | ✅ | ✅ | ❌ |
| Отметить посещаемость | ✅ | ✅ | ❌ |
| Мои данные | ❌ | ❌ | ✅ |

### Пункты меню

```
0.  Сменить роль
1.  Добавить студента
2.  Удалить студента
3.  Добавить расписание
4.  Показать студентов
5.  Показать оценки всех студентов
6.  Добавить оценку
7.  Добавить ДЗ
8.  Отметить посещаемость
9.  Мои данные (для студента)

```

### Вход студента

1. Выберите пункт `0` → роль `3` (Студент)
2. Введите **ID** студента (выдаётся при создании)
3. Введите пароль (по умолчанию `123`)

## 🗄 Формат базы данных

Файл `students.db` — бинарный, с заголовком `STUDENTS_DB_V1`.
Каждая строка сериализуется с префиксом длины, что позволяет хранить
строки с пробелами и спецсимволами.

```
STUDENTS_DB_V1
<next_id>
<student_count>
<student_record>...
```

## 🧩 Архитектура

### Основные компоненты

- **`Student`** — класс с полями: ID, имя, фамилия, группа, курс,
  средний балл, тип обучения, пароль, оценки, ДЗ, посещаемость, расписание
- **`Role`** — перечисление ролей: `ADMIN`, `TEACHER`, `STUDENT`
- **`EducationType`** — тип обучения: `BUDGET`, `PAID`
- **Валидация** — функции `isValidName`, `isValidGroup`, `isValidDate`, `isValidTime`
- **Сериализация** — `writeString` / `readString`, `writeVec` / `readVec`
- **Утилиты** — `askLine`, `askInt`, `askName`, `askGroup`, `askDate`, `askTime`

## ⚠️ Известные ограничения

- Русские буквы в `std::regex` работают **только при кодировке Windows-1251**
  и соответствующей локали. На Linux/macOS с UTF-8 валидация имён и групп
  может не срабатывать.
- Пароль студента хранится в открытом виде (учебный проект).
- Данные сохраняются после каждого действия — при большом количестве
  студентов это может замедлить работу.
